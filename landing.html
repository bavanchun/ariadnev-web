Graph-native execution

Release turns three canonical delivery workflows into versioned graph contracts, rejects unsafe structure, and keeps local runs recoverable.

Graph IR

Versioned JSON contracts make nodes, edges, authority, state ownership, and failure paths explicit.

Lint

Reject unreachable nodes, unbounded loops or retries, missing failure edges, and authority gaps before execution.

Execute

A provider-neutral runner emits redacted append-only events while adapters handle runtime-specific invocation.

Resume

Checkpoints, idempotency leases, and reconciliation recover defined failures without duplicate effects.
