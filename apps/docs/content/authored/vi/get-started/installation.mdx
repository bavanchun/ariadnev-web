Bộ cài tải binary cho nền tảng của bạn từ `ariadnev.com`, xác minh sha256 với checksums đã công bố, cài đặt, rồi tạo bí danh ngắn `av` ngay cạnh. CLI không cần Node runtime.

## macOS và Linux

```bash
curl -fsSL https://ariadnev.com/install | bash
```

Cài vào `~/.local/bin`. Đổi thư mục đích bằng `ARIADNEV_INSTALL_DIR`.

## Windows (PowerShell)

```powershell
irm https://ariadnev.com/install.ps1 | iex
```

Cài vào `%LOCALAPPDATA%\Programs\ariadnev`.

## Bộ cài làm gì

1. Lấy phiên bản phát hành hiện tại từ `https://ariadnev.com/version`.
2. Tải `ariadnev-<os>-<arch>` và `checksums.txt` từ `https://ariadnev.com/download/`.
3. Xác minh sha256 của binary trước khi ghi ra bất kỳ đâu.
4. Tạo `av` cạnh binary. Bỏ qua bằng `ARIADNEV_ALIAS=off`; một `av` có sẵn không bao giờ bị ghi đè.

Muốn đọc script trước? Mở [https://ariadnev.com/install](https://ariadnev.com/install) — chính là đường dẫn ẩn danh mà lệnh trên tải về.

## Gatekeeper trên macOS

Binary chưa được notarize, nên lần chạy đầu có thể bị chặn. Cho phép bằng:

```bash
xattr -d com.apple.quarantine "$(command -v ariadnev)"
```

> **Bỏ một lớp an toàn của macOS.** Thuộc tính quarantine là cách macOS cảnh báo về file tải xuống chưa ký. Chỉ chạy lệnh này sau khi installer ở trên đã xác minh sha256, hoặc sau khi bạn tự tải binary về và đối chiếu với `https://ariadnev.com/download/checksums.txt` cho cùng phiên bản.

## Tùy chọn: hook cho Claude Code

Bản thân CLI tự chứa. Các hook Claude Code tùy chọn mà kit đóng gói là các tiến trình `.cjs` riêng và cần `node` trong PATH khi bạn bật chúng.

```bash
ariadnev --version
av --version
```
